# Why this review exists

We tracked what happens to a deck when concrete accessibility fixes are applied
to real presentations, not lab decks.

- Every slide in the study was a real team deck
- Every fix was measured before and after
- Every result is reproducible from the public data set

Note:
Anchor the study in practice. The decks were shared internally and externally,
so the fixes had to survive real use.

# Before and after

::column-left
### Before
- Auto-generated headings
- Link text: *click here*
- Images without alt text
::

::column-right
### After
- One descriptive H1 per slide
- Link text names the destination
- Alt text explains the content
::

The same study slide, thirty minutes of authorial effort apart.

Read the right column as the checklist. Nothing here required a developer.

# What we found

The three checks that caught the most issues, in order:

1. One H1 per slide
2. Alt text that explains the content
3. Link text that names the destination

Note:
Order matters: the cheapest check catches the most. Start there before
touching visual design.
